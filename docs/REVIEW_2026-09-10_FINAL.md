# 최종 리뷰 — 2026-09-10

대상: NTS 0.27.10, OLTA 0.1.3. 설계·중요 디버깅·의미 검증은 Astra low, 릴리스 파일 정리와 기계적 검증은 Luna max로 진행했다.

## 재현 및 수정

1. 양쪽 MCP: 적용례에 2027년 적용일이 있어도 일반 시행일 2026년으로 적용을 안내했다. 명시연도가 있는 신고·행위·소득 적용례는 원문 대조 전 판정을 유보한다.
2. 양쪽 MCP: `2025년 12월 31일까지`라는 경과조건에서 2024년을 숫자 불일치로 배제했다. 월일을 포함한 범위도 원문 대조로 유보한다.
3. NTS: 신구조문 비교의 두 XML이 모두 같은 다른 법령이면 정상 비교했다. 각 XML 제명을 요청 법령명과 대조하여 불일치를 거부한다.

각 반례는 수정 전 실패를 확인하고 회귀 테스트로 유지했다. 수정 후 전체 테스트는 NTS 384개, OLTA 62개 통과했다. 원문 발췌와 유보 안내가 실제 trace/timetable 출력에 함께 전달되는 경로를 확인했다.

## 네 가지 관점

- 효과성: 잘못된 적용 단정과 다른 법령의 비교를 차단한다. 플랫폼의 구조 복원과 법적 적용 판단을 분리하는 원칙을 유지한다.
- 토큰 효율성: 추가 검색이나 장문 분석 없이 기존 응답의 짧은 검증·유보 안내로 처리한다. 토큰 절감률은 측정하지 않았다.
- 작업시간: 새 네트워크 호출을 추가하지 않는다. 이번 수정의 처리시간 개선 수치는 측정하지 않았다.
- 보안: 양쪽 production dependency audit 0건. 전송·리다이렉트·캐시·인용 경로의 제한된 추가 검토에서 새 중요 반례는 확인하지 못했다. 전수 보안 감사를 의미하지 않는다.
